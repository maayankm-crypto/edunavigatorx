# EduNavigatorX.ai

Static website for EduNavigatorX.ai, powered by The Chopras.

## Preview
Open `index.html` in a browser. No build step is required. Images are embedded in the HTML; external font and script resources require an internet connection.
## Waitlist forms
Separate university and student forms are included. They validate fields locally but do not transmit or save submissions; a backend must be connected before registration opens.
